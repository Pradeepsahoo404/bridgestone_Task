# Socially Approved Video Carousel 🎥✨

A production-quality, full-stack video reel carousel application built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Swiper.js**, **TanStack Query**, and **Node.js/Express**. Inspired by modern e-commerce visual standards (such as driptrip.in).

---

## 🚀 Quick Setup & Launch Instructions

To clone and run the application locally from scratch:

```bash
# 1. Clone the repository
git clone https://github.com/example/socially-approved-carousel.git
cd socially-approved-carousel

# 2. Install all dependencies (Root, Backend, and Frontend)
npm run install:all

# 3. Start development server (Runs Frontend & Backend concurrently)
npm run dev
```

### URLs
- **Frontend App**: [http://localhost:3000](http://localhost:3000)
- **Backend API**: [http://localhost:5000/api](http://localhost:5000/api) (Health endpoint: `http://localhost:5000/api/health`)
